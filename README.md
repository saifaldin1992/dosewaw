# DOSEWAW

مرجع الجرعات للصيادلة: المضادات الحيوية، وخافضات الحرارة والمسكنات، ومضادات الهيستامين والكورتيزونات، وأدوية الجهاز الهضمي، والفيتامينات.

## المرحلة 0 — نموذج التصميم
- `design/phase0/index.html`: نموذج تفاعلي لصفحة الدواء (مثال: أموكسيسيلين، نشرة DailyMed 2026-07-07).
- `design/phase0/shots/`: صور النموذج على الجوال والآيباد والكمبيوتر، والوضع الليلي.

## الهوية البصرية (منفصلة عن الكود)
- `design/phase0/brand/theme.css`: كل الألوان والخطوط والأشكال، مع الوضع الليلي.
- `design/phase0/brand/brand.js`: اسم الموقع والعبارة وملف الشعار ولون شريط المتصفح.
- `design/phase0/brand/logo.svg`: الشعار.

تغيير أي قيمة في هذه الملفات يغيّر شكل الموقع كله بدون لمس الكود. في الموقع النهائي ستكون هذه القيم قابلة للتعديل من لوحة المالك.

النموذج للعرض والموافقة فقط، وليس الموقع النهائي.
